# Form Atlas · 曲式理论地图

这是音乐理论工作台中的曲式系统。它把曲式判断拆成四个可以分别核验的问题：

1. 材料是否相同、变化或对比；
2. 段落在哪里形成终止与结构闭合；
3. 调性离开哪里、回到哪里；
4. 段落的层级、比例、织体与速度如何支持这种划分。

页面中的每个理论判断都对应 `evidence/source-map.json` 中的教材物理页；案例另记录作品、段落结构、调性路径和教材分析页。所有引用页码均为 PDF 物理页，与书内印刷页码分开。

## 构建

```powershell
cd form_atlas
npm test
npm run build
```

`tools/build_books.py` 只渲染被引用的教材页，公开部署不包含完整扫描书。`tools/build_manual.py` 从同一份证据数据生成手册，避免页面与依据脱节。
