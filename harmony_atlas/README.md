# 和声推演台 · Harmony Atlas

交互式和声学习系统，包含和声进行推演、转调路径、和弦库、音级集合、理论地图、试听、MIDI 导出与理论手册。

## 入口

- 推演台：`app/index.html`
- 理论手册：`docs/和声学手册.html`
- 教材证据索引：`docs/books/index.html`

## 公开部署版

本目录保留完整应用、理论手册、结构化证据与手册实际引用的 15 册教材中的 194 个页面。每页同时保留：

- 页内论点锚点，供手册直接跳转；
- 整页影印；
- OCR 文本；
- 手册引用关系。

未引用扫描页、`_work/`、浏览器产物和缓存不进入公开仓库。

## 本地运行

```powershell
python -m http.server 8765
```

打开 `http://127.0.0.1:8765/app/index.html`。不启动服务器时，直接打开 `app/index.html` 也可以使用全部本地推演功能。

## 测试

```powershell
npm test
```

测试覆盖和弦目录、证据图、音高与调式、集合运算和声部连接。

## 数据目录

- `corpus/`：定向 OCR 与书籍索引。
- `evidence/`：网页和手册共享的证据数据。
- `tools/`：教材归档、文档构建和 OCR 工具。
- `tests/`：数据完整性与音乐规则测试。

原 PDF 跳转依赖本地教材文件和专用服务；公开静态版保留扫描页与页内锚点，因此所有手册引用仍然可以直接核验。
