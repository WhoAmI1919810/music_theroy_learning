<div class="ocr-text">序<br>
这本书是童忠良同志研究近现代和声的一篇论文，1979年<br>
11月在武昌湖北艺术学院举办的具有全国性规模的“和声学学术<br>
报告会”上公开发表，受到很多同志的重视。<br>
同主音大小调互换，已是传统和声的常用手法；而同中音大<br>
小调互换，则是现代和声手法。它引起了调性的扩张，结成繁复<br>
的和声功能网。<br>
正如作者在前言里所说的那样：“插上功能族的翅膀”，<br>
“驰骋于重同名之间”，“音级与功能一体”，“重新划分三大<br>
功能”—这些想法在书中都已得到细致的叙述和有力的证明。<br>
作者还利用“宫角轴”理论将我国民族调式作了类似的扩展，使<br>
形成统一的整体。<br>
据说作者青年时，在国外学习期间便开始探索这个问题。现<br>
在虽经成长，具有规模，但随着新的音乐作品不断问世，肯定有<br>
许多新问题需要继续努力深人探索的。我作为学习，特此介绍。<br>
江定仙<br>
