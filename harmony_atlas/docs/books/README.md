## 使用说明

- 每册 Markdown 的每个被引用页先给整页图，再给 OCR 文本；点击图片可打开原尺寸。
- OCR 用于检索、复制和定位，谱例、临时记号、罗马数字与连线以整页图为准。
- 被理论手册引用的页面在图后列出“手册使用本页”，其中包括论点提炼、案例的原书要点与机制、阶段依据和正文引用，并可回跳到手册中的对应条目。
- 快速跳页在每册开头列出全部已发布引用页；每页也有 `p0001` 形式的锚点。
